## Лабораторная работа №1
Допустим, что вы решили оригинально и немного странно познакомится с человеком. Для этого у вас должен быть написан свой класс на Python, 
который будет проверять угадал ваше имя человек или нет. Для этого создайте класс, указав в свойствах только имя. Дальше создайте функцию 
__init__(), а в ней сделайте проверку на то угадал человек ваше имя или нет. Также можете проверить что будет, если в этой функции указав 
атрибут, который не указан в вашем классе, например, попробуйте вызвать фамилию.

```python
class Ivan:
    __slots__ = ['name']

    def __init__(self, name):
        if name == 'Иван':
            self.name = f"Да, я {name}"
        else:
            self.name = f"Я не {name}, a Иван"

person1 = Ivan('Алексей')
person2 = Ivan('Иван')
print(person1.name)
print(person2.name)
person2.surname = 'Петров'
```

## Лабораторная работа №2
Вам дали важное задание, написать продавцу мороженого программу, которая будет писать добавили ли топпинг в мороженое и цену после возможного изменения. 
Для этого вам нужно написать класс, в котором Михаил А. Панов будет определяться изменили ли состав мороженого или нет. В этом классе реализуйте метод, 
выводящий на печать «Мороженое с {ТОППИНГ}» в случае наличия добавки, а иначе отобразится следующая фраза: «Обычное мороженое». При этом программа должна 
воспринимать как топпинг только атрибуты типа string.

```python
class Icecream:
    def __init__(self, ingredient=None):
        if isinstance(ingredient, str):
            self.ingredient = ingredient
        else:
            self.ingredient = None

    def composition(self):
        if self.ingredient:
            print(f"Мороженое с {self.ingredient}")
        else:
            print('Обычное мороженое')

icecream = Icecream()
icecream.composition()
icecream = Icecream('шоколадом')
icecream.composition()
icecream = Icecream(5)
icecream.composition()
```

## Лабораторная работа №5
На разных языках здороваются по-разному, но суть остается одинаковой, люди друг с другом здороваются. Давайте вместе с вами реализуем программу с полиморфизмом, 
которая будет описывать всю суть первого предложения задачи. Для этого мы можем выбрать два языка, например, русский и английский и написать для них отдельные классы, 
в которых будет в виде атрибута слово, которым здороваются на этих языках. А также напишем функцию, которая будет выводить информацию о том, как на этих языках здороваются. 
Заметьте, что для решения поставленной задачи мы использовали декоратор @staticmethod, поскольку нам не нужны обязательные параметры-ссылки вроде self.

```python
class Russian:
    @staticmethod
    def greeting():
        print("Привет")

class English:
    @staticmethod
    def greeting():
        print("Hello")

def greet(language):
    language.greeting()

ivan = Russian()
greet(ivan)
john = English()
greet(john)
```

## Самостоятельная работа №1
Условие прописано в файле, что на портале.

```python
class Tomato:
    states = ('отсутствует', 'цветение', 'зеленый', 'красный')

    def __init__(self, index):
        """
        Инициализатор класса Tomato.
        :param index: Индекс томата (порядковый номер).
        """
        # _index: защищенное (protected) свойство, хранит индекс томата.
        self._index = index
        # _state: защищенное (protected) свойство, хранит индекс текущей
        # стадии созревания из кортежа 'states'. Начинается с 0 ('отсутствует').
        self._state = 0

    def grow(self):
        """
        Переводит томат на следующую стадию созревания,
        если он еще не достиг последней.
        """
        if self._state < len(Tomato.states) - 1:
            self._state += 1
            print(f"Томат {self._index} перешел на стадию: {Tomato.states[self._state]}")
        else:
            print(f"Томат {self._index} уже созрел (стадия: {Tomato.states[self._state]}).")

    def is_ripe(self):
        """
        Проверяет, созрел ли томат (достиг ли последней стадии).
        :return: True, если томат созрел, иначе False.
        """
        return self._state == len(Tomato.states) - 1

    def __str__(self):
        return f"Томат {self._index} (Стадия: {Tomato.states[self._state]})"



class TomatoBush:

    def __init__(self, num_tomatoes):
        """
        Инициализатор класса TomatoBush.
        :param num_tomatoes: Количество томатов, которое будет на кусте.
        """
        self.tomatoes = [Tomato(i) for i in range(num_tomatoes)]
        print(f"Создан куст с {num_tomatoes} томатами.")

    def grow_all(self):
        """
        Запускает "рост" (переход на следующую стадию)
        для каждого томата в списке 'tomatoes'.
        """
        print("\nКуст с помидорами растет...")
        for tomato in self.tomatoes:
            tomato.grow()

    def all_are_ripe(self):
        """
        Проверяет, созрели ли ВСЕ томаты на кусте.
        :return: True, если все томаты созрели, иначе False.
        """
        # Функция all() вернет True, только если is_ripe()
        # вернет True для каждого томата в списке.
        return all(tomato.is_ripe() for tomato in self.tomatoes)

    def give_away_all(self):
        """
        "Отдает" урожай (очищает список томатов).
        """
        print("Урожай собран! Куст очищен.")
        self.tomatoes = []

    # Вспомогательный метод для отображения состояния куста
    def print_bush_state(self):
        print("Текущее состояние куста:")
        if not self.tomatoes:
            print("Куст пуст (урожай собран).")
            return
        for tomato in self.tomatoes:
            print(f"  - {tomato}")



class Gardener:
    def __init__(self, name, plant):
        """
        Инициализатор класса Gardener.
        :param name: Имя садовника.
        :param plant: Объект класса TomatoBush, за которым ухаживает садовник.
        """
        self.name = name
        self._plant = plant

    def work(self):
        """
        Садовник "работает" - ухаживает за растением,
        что заставляет все томаты на нем расти.
        """
        print(f"\nСадовник {self.name} ухаживает за растением.")
        self._plant.grow_all()

    def harvest(self):
        """
        Садовник пытается собрать урожай.
        Проверяет, созрели ли все плоды.
        """
        print(f"\nСадовник {self.name} пытается собрать урожай...")
        if self._plant.all_are_ripe():
            # Если все созрели - собирает урожай
            print(f"Ура! {self.name} собирает спелые помидоры.")
            self._plant.give_away_all()
        else:
            # Если нет - выводит предупреждение
            print("ПРЕДУПРЕЖДЕНИЕ: Томаты еще не созрели! Рано собирать.")

    @staticmethod
    def knowledge_base():
        """
        Выводит в консоль справку по садоводству.
        """
        print("\n--- Справка по садоводству (Knowledge Base) ---")
        print("1. Помидоры проходят 4 стадии: 'отсутствует', 'цветение', 'зеленый', 'красный'.")
        print("2. Урожай можно собирать только тогда, когда ВСЕ плоды 'красные'.")
        print("3. Регулярный уход (метод work()) ускоряет созревание.")
        print("-------------------------------------------------")



if __name__ == "__main__":
    print("=" * 40)
    print("Тест 1: Вызов справки по садоводству")
    Gardener.knowledge_base()

    print("\n" + "=" * 40)
    print("Тест 2: Создание объектов")
    my_bush = TomatoBush(3)
    ivan = Gardener("Иван", my_bush)
    print(f"Садовник {ivan.name} и его куст созданы.")
    my_bush.print_bush_state()

    # Уход за кустом (1-й раз)
    # Стадии: отсутствует (0) -> цветение (1)
    print("\n" + "=" * 40)
    print("Тест 3: Уход за кустом (1-й раз)")
    ivan.work()
    my_bush.print_bush_state()

    # Попытка сбора урожая
    print("\n" + "=" * 40)
    print("Тест 4: Попытка сбора незрелого урожая")
    ivan.harvest()

    # Продолжаем ухаживать
    print("\n" + "=" * 40)
    print("Тест 4 (продолжение): Дальнейший уход")

    # Уход 2-й раз: цветение (1) -> зеленый (2)
    ivan.work()

    # Уход 3-й раз: зеленый (2) -> красный (3)
    # На этой стадии все томаты должны стать спелыми
    ivan.work()

    my_bush.print_bush_state()  # Проверяем, что все красные

    # Сбор урожая
    print("\n" + "=" * 40)
    print("Тест 5: Сбор созревшего урожая")
    ivan.harvest()

    # Проверяем состояние куста после сбора
    print("\n--- Проверка куста после сбора ---")
    my_bush.print_bush_state()
```
